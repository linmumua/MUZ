## 上一轮已完成的主线迭代摘要

根据上次迭代会话总结，主线在 `1.6.17` 之前后续又补进了以下能力：

### 1. 牌桌放置 / 拆除工具链重做

- `/muz give` 改为显式玩法参数格式，支持斗地主与德州两种放桌器。
- 放桌器默认场次为 `fun`，并修正了自动补全错误补出 `1` 的问题。
- 放桌成功后会自动发放与该桌绑定的拆桌棍。
- 拆桌棍由斧头改为木棍，并通过专用 NBT 绑定到具体玩法与具体桌号。
- lore 会直接显示桌子 `ID`，逻辑上只能拆对应那一张桌。
- 拆桌时会回收木棍并返还对应玩法、对应桌号、对应场次的放桌器。
- 斗地主与德州两边都支持放置者 owner 校验，owner 会持久化保存；旧桌若没有 owner，则默认仅管理员可拆。

### 2. 放置预览与阻挡反馈增强

- 放桌器放置前会先检查桌面与座位空间占用情况。
- 若桌面或任一侧椅子 / 座位被方块挡住，会通过 actionbar 给出失败提示。
- 同时会把具体被挡住的位置用红色粒子直接圈出，方便现场定位。
- 德州牌桌的空位 join 文案位置也修正为跟随按钮文本高度配置。

### 3. 保护、音乐与回合体验修补

- 进一步加强了对 CE 家具、CE 方块和原版方块的保护。
- 新增 CraftEngine 原生事件层的兜底取消逻辑，并在生成的 CE 家具配置里设置极高 `hit-times`。
- 修复了玩家离桌、掉线与对局结束后的音乐停止逻辑，保证结束后立即停歌。
- 处理了结算胜利显示与未准备提示之间的冲突，先完整展示胜利信息，再恢复未准备提示。
- 随机语音触发逻辑增加防重复限制，避免同一条随机语音连续三次被选中。

### 4. 聊天输入静默处理与菜单交互

- 管理菜单中的音效、颜色等聊天栏传参改成更严格的静默拦截方式。
- 同时兼容现代 `AsyncChatEvent` 与旧版聊天事件。
- 玩家输入参数后不会再正常广播到公屏。
- 管理员菜单新增“放置阻挡警告音”编辑入口，继续沿用聊天输入参数方式。

### 5. 外部 AI / Bot 决策链路接入

- 外部 AI 已实际接入斗地主 Bot 的叫分、加倍和出牌流程。
- 新增 `bot.ai.enabled` 与 `bot.ai.timeout-ms` 配置项。
- 当 DeepSeek 可用时优先用外部 AI 决策；若未配置、超时、空返回或非法结果，则自动回退到 `SimpleBotBrain`。
- 真人玩家超时后也支持“托管出牌”，优先尝试 DeepSeek，失败则回退到本地默认 AI。
- 每次 DeepSeek prompt、返回、解析结果、是否生效、是否回退等信息都会以 YAML 写入插件数据目录下的 `bot/` 文件夹，方便排查。

## 当前主线已确认纳入的能力面

### 1. GUI / 交互继续扩展

- 保留并扩展了管理员 GUI，多页配置覆盖模型、渲染、音频、机器人等维度。
- 支持个人设置 GUI，不在牌桌里也能打开。
- 支持私人手牌位置、间距、预览尺寸、标签显示等个人微调。
- 持续增强按钮 hover、按钮弧线排布、命中箱与文本提示配置。

### 2. 构建与资源生成增强

- `build.gradle.kts` 中已经集成资源包生成、CraftEngine bundle 生成与 zip 打包流程。
- 启动与重载阶段会补强 bundle 导出与兼容处理。
- README 中当前构建产物已经应该以 `1.6.17` 为准。

### 3. 经济与数据层扩展

- 经济系统支持金币 / 筹码两种模式。
- 支持 Vault 挂钩、provider 优先级与汇率配置。
- 数据层支持 SQLite / MySQL。
- 支持历史战绩查询、牌桌恢复与持久化存储。

### 4. AI 接口接入

- 主线已提供默认关闭的 OpenAI 兼容 AI gateway。
- 可以通过配置改 `base-url / api-key / model` 对接 DeepSeek 或其他兼容服务。
