This project bundles card face textures, UI graphics, and sound effects derived from the upstream 斗地主 resource pack release:

- Repository: https://github.com/tml104/-Minecraft-Dou-Dizhu
- Release asset: https://github.com/tml104/-Minecraft-Dou-Dizhu/releases/download/v1.3/DouDizhu.Resource.pack.v1.3.zip

The upstream repository does not publish an explicit license file for these art/audio assets.
Before redistributing this plugin or its generated packs publicly, verify the original author's redistribution terms.
